2 Router PR Configuration (Full Script)

Connect a Console Cable from PD-1-23 (RS-232) to Police (Console). Click PC → Desktop → Terminal (9600-8-N-1):

📋 Router PR Complete Configuration (Copy & Paste) 
enable
configure terminal

! 1. Set Hostname
hostname PR

! 2. Disable DNS lookup to avoid typos hanging the CLI
no ip domain-lookup

! 3. Configure MOTD Banner
banner motd #No Unauthorized Access#

! 4. Configure IP Domain Name
ip domain-name CCNA.net

! 5. Create Admin user with privilege 15 (Do this BEFORE password min-length!)
username Admin privilege 15 secret Adminpa55

! 6. Set Password Minimum Length to 10
security passwords min-length 10

! 7. Set Encrypted Enable Secret Password
enable secret Ciscoenpa55

! 8. Enable Plaintext Password Encryption
service password-encryption

! 9. Configure Console Line Security with 10-minute timeout
line console 0
 password Ciscoconpa55
 login
 exec-timeout 10 0
 exit

! 10. Configure VTY Lines for SSH, local authentication, and 10-minute timeout
line vty 0 4
 transport input ssh
 login local
 exec-timeout 10 0
 exit

! 11. Generate RSA 1024-bit Crypto Key for SSH
crypto key generate rsa
1024

! 12. Configure Login Banner
banner login #No Unauthorised Access#

! 13. Block Login for 3 mins (180s) after 4 failed attempts within 30s
login block-for 180 attempts 4 within 30

! 14. Configure Interface Fa0/0 (LAN-Sales)
interface FastEthernet0/0
 description SALES
 ip address 49.50.10.1 255.255.255.128
 no shutdown
 exit

! 15. Configure Interface Fa0/1 (LAN-Design)

 exit

! 16. Configure Interface E0/0/0 (LAN-Admin)

6. Critical Exam Traps & Gotchas

⚠️ Trap 1: Password Minimum Length vs "Adminpa55"

The requirement specifies a minimum password length of 10 characters, but also asks to configure user Admin with password Adminpa55 (which is only 9 characters). If you set security passwords min-length 10 first, IOS will reject username Admin ... secret Adminpa55!
Solution: Configure the username first, then configure security passwords min-length 10.

⚠️ Trap 2: Login Block Seconds vs Minutes

The prompt says: "Configure block for 3 mins after 4 failed attempts within 30 seconds".
Cisco IOS takes block time in seconds, not minutes!
Correct command: login block-for 180 attempts 4 within 30 (3 × 60 = 180 seconds).

💡 Trap 3: Default Gateway Placement on Switches

ip default-gateway <IP> is a global configuration command. If you type it inside interface vlan 1, it will be rejected as invalid syntax.

💡 Trap 4: First Ping Times Out (ARP Resolution)

In Packet Tracer, the very first packet of an ICMP ping to a new IP often shows Request timed out due to ARP address resolution. The next 3 packets will reply with Reply from .... Re-running the ping gives 100% success.
