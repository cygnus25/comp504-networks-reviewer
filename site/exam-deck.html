PDU names per layer — a reliable MCQ

  • Transport layer PDU = segment (TCP) or datagram (UDP)
  • Network layer PDU = packet
  • Data link layer PDU = frame
  • Physical layer = bits; it is the only layer that does not create a new PDU

Process — encapsulation, sender side

  1. User clicks a link. The browser translates the request into HTTP and passes the HTTP packet down.
  2. Transport (TCP) places the HTTP packet inside a TCP segment, adding ports and sequence numbers.
  3. Network (IP) places the TCP segment inside an IP packet and selects the next stop on the route.
  4. Data link (Ethernet) adds start/stop markers and error-check information, forming a frame.
  5. Physical transmits the Ethernet frame as a series of electrical pulses down the cable.

Standards

  • De jure = official / formal, developed by an industry or government body. Three stages: specification → identification of choices → acceptance.
  • De facto = emerged in the marketplace, supported by several vendors, no official standing.
  • IEEE → 802.3 Ethernet, 802.11 wireless LAN. ISO → OSI model (1984), members are national standards bodies. IETF → Internet standards. ITU-T → UN telecom body. ANSI → US coordinating body.
  • Primary reason standards exist: so hardware and software from different vendors can work together.

Must know

Circuit configuration — named on the exam slide

  • Two fundamental configurations: point-to-point and multipoint.
  • Point-to-point = from one point to another; also called a dedicated circuit. Expensive, as each computer needs its own circuit.
  • Multipoint = many computers connected to the same circuit; also called a shared circuit. Only one computer can use it at a time, but it's more efficient and uses less cable.

Data flow — three terms, learn the examples

ModeDefinitionSlide's example
SimplexOne-way transmissionRadios and TVs
Half-duplexTwo-way, but only one direction at a timeWalkie-talkie
Full-duplexBoth directions simultaneously—

The delay when half-duplex switches between sending and receiving is turnaround time.

Attenuation — flagged explicitly on the exam slide

Attenuation is the weakening of a signal over distance. The fix is adding repeaters or amplifiers to a circuit. Do not confuse it with the fix for impulse noise / cross-talk / intermodulation noise, which is shielding wires.

Connects toCh 7 LANs: hubs and switches act as repeaters precisely because signals attenuate in cable. A quiz item in Ch 7 tests exactly this.

Media — guided vs wireless

  • Two basic types: guided (message flows through a physical medium) and wireless / radiated (broadcast through air).
  • Guided: twisted-pair, coaxial, fiber-optic. Wireless: radio, microwave, satellite.
  • Fiber-optic best withstands harsh environmental conditions and is least susceptible to noise. Light pulses from lasers or LEDs; single-mode core reduced from 50 microns to about 5–10 microns; effective distance just under 1,000 m.
  • Twisted pair wires are twisted to minimise electromagnetic interference. Coaxial has a copper core, the outer shield is the second conductor. Microwave is line-of-sight, long distance, no cable laying. Satellite is geosynchronous; disadvantages are propagation delay and raindrop attenuation.
  • Six media selection factors: type of network, cost, transmission distance, security, error rates, transmission speed.

Straight-through vs crossover cable

  • DTE (Data Terminal Equipment) = end-user stations: computers, laptops, Ethernet printers. DCE (Data Circuit Equipment) = switching and routing devices: switches, hubs, routers.
  • Crossover connects DCE-to-DCE or DTE-to-DTE. The two wiring standards are T568A and T568B; they differ in the position of the orange and green wire pairs.

Multiplexing — four types

Multiplexing breaks one high-speed physical circuit into several lower-speed logical circuits. Often done in multiples of 4.

TypeMechanism
FDM — frequency divisionDivides the circuit "horizontally"; many signals travel simultaneously
TDM — time divisionComputers take turns
STDM — statistical time divisionSpeed chosen by statistical analysis of usage requirements
WDM — wavelength divisionA version of FDM used in fiber-optic cables
Connects toCh 10: ADSL uses FDM to create three channels on one local loop; Fiber to the Home uses WDM. Both appear as direct quiz answers.

Digital transmission and encoding

  • Five benefits of digital over analog: fewer errors, higher maximum rates, more efficient, more secure (easier to encrypt), simpler to integrate voice/video/data.
  • Unipolar: 0 V for a zero, +5 V for a one. Bipolar: varies plus to minus — NRZ (never returns to 0), RZ (returns to 0 after each bit), AMI (0 always 0 V, 1s alternate ±5 V).
  • Ethernet uses Manchester encoding — a special type of bipolar signalling where the signal changes in the middle of the signal. High→low = 0; low→high = 1. Less susceptible to undetected errors, because no mid-signal transition means an error occurred.
  • Parallel = all 8 bits at once on 8 wires (inside a computer). Serial = bit-by-bit on one wire; much slower.
  • Coding schemes: ASCII, ISO 8859, Unicode (UTF-8 ≈ ASCII, UTF-16 used by Windows).

Analog transmission & modulation

  • Three characteristics of a sound wave: amplitude (height, in decibels), frequency (length, in hertz), phase (direction the wave begins, in degrees).
  • Three modulation techniques: AM / amplitude shift keying (ASK) — most susceptible to noise; FM / frequency shift keying (FSK); PM / phase shift keying (PSK).
  • Bit rate = bits per second. Baud rate = number of times per second the signal changes. Equal only when 1 bit is sent per symbol.
  • Bandwidth = difference between highest and lowest frequencies. Standard telephone lines = 4,000 Hz.
  • Modem = modulator/demodulator (digital ↔ analog). Codec = code/decode (analog voice → digital). Quantizing error is reduced by increasing amplitude levels or sampling more frequently.

Good to know

V.44 compression using Lempel–Ziv (averages 6:1); ADPCM transmitting the difference between 8-bit values; the local loop / "last mile"; Auto MDI-X making crossover cables largely unnecessary on modern hardware.

Must know

Role and position — quoted almost verbatim on the exam slide

  • Responsible for communications between end-device network interface cards.
  • Allows upper layer protocols to access the physical layer media and encapsulates Layer 3 packets (IPv4 and IPv6) into Layer 2 frames.
  • Performs error detection and rejects corrupted frames.
  • It does not specify the type of connection or the electrical signals, radio waves or light pulses that pass through it.
  • It sits directly between the physical and the network layers. It does not perform routing.

Two sublayers

  • LLC (Logical Link Control) — the data link layer's connection to the network layer above; communicates between upper-layer software and lower-layer hardware.
  • MAC (Media Access Control) — controls the physical hardware; responsible for data encapsulation and media access control.

Three functions of a data link protocol

  1. Media access control — controls when computers transmit.
  2. Error control — detects and corrects transmission errors.
  3. Message delineation — identifies the start and end of a message using a PDU.

Amplitude shift keying is not a data link function — that's a physical layer modulation technique, and it appears as a distractor.

Media access control — two fundamental approaches

  • Roll-call polling — the controller works consecutively through a list of clients.
  • Hub polling (often called token passing) — one device starts the poll and passes it to the next computer on the multipoint circuit.
  • With point-to-point full-duplex, media access control is unnecessary.

Error sources and their fixes — a dense quiz cluster

  • Two categories of network error: corrupted data and lost data. Networks are designed to (1) prevent, (2) detect, (3) correct.
  • Single-bit error = one 0 becomes a 1 or vice versa. Burst error = multiple bits changed. Errors normally appear in bursts, not uniformly distributed.

Three error detection techniques — verbatim on the exam slide

Forward error correction uses enough redundancy to correct errors at the receiving end without retransmission; commonly used in satellite transmission. In practice, most LAN data link software is configured to detect errors but not correct them — a packet with an error is simply discarded.

Asynchronous vs synchronous, and the four synchronous protocols

  • Asynchronous (start–stop) — each character is transmitted independently of all other characters, with a start bit and stop bit around each one.
  • Synchronous — all data in one group transmitted at once as a block called a frame; only the start and end of the whole frame are marked.
  • Four synchronous protocols: SDLC, HDLC, Ethernet, PPP. (VT100 is the classic distractor — it is not one.)
ProtocolKey identifying facts
SDLCIBM mainframe protocol, 1972. Begins and ends with the flag bit pattern 01111110. Frame check sequence is a 32-bit CRC.
HDLCISO formal standard, used in WANs. Same as SDLC but address and control fields can be longer; larger sliding window for continuous ARQ; uses a controlled-access protocol.
Ethernet (802.3)Conceived by Bob Metcalfe in 1973. Contention-based. Starts with a 7-byte preamble, then start of frame delimiter. Optional 4-byte VLAN tag. Ends with a CRC-32. Newer versions permit jumbo frames.
PPPEarly 1990s, often used in WANs. Point-to-point but has an address so it works on multipoint. Data field up to 1,500 bytes. FCS usually CRC-16, can be CRC-32.

Transmission efficiency

Transmission efficiency = total information bits ÷ total bits in transmission. General rule: the larger the message field, the more efficient the protocol. Throughput is the total information bits received per second, accounting for overhead and retransmissions.

Layer 2 addressing and MAC spoofing

  • A Layer 2 address is also called a physical address. It is used only for local delivery on the link and is updated by each device that forwards the frame.
  • MAC address filtering lists which MAC addresses may connect. It gives a false sense of security because of MAC address spoofing — a software-enabled technique that changes the hardcoded MAC address.
Connects toCh 7 and Ch 11 both return to MAC address filtering. Ch 7 states plainly: it "provides no security against a determined hacker."

Good to know

The generic frame field table (start/stop, addressing, type, control, data, error detection); SDLC information vs supervisory frames; DSAP/SSAP fields; bus and ring topologies from early Ethernet and legacy Token Ring.

Must know

Six LAN components

  1. Client computer
  2. Server
  3. Network interface cards (NICs)
  4. Network circuits
  5. Hubs / switches / access points
  6. The network operating system
  • The NIC physically connects a computer to the network cable. In a wireless network the NIC is a radio transceiver.
  • Hubs and switches serve two purposes: an easy way to connect cables, and they act as repeaters to regenerate signals so attenuation does not occur. Each connection point is a port with a unique number.
  • An access point (AP) is a radio transceiver playing the same role as a hub or switch in wired Ethernet. Most WLANs use APs with omnidirectional antennas.
  • Most LANs use UTP. STP is used only in areas producing electrical interference. Fiber-optic is thinner than UTP and takes less space.

Network operating system (NOS) — a known trap

  • Server NOS performs functions of the data link, network, and application layers, plus the computer's own OS. It replaces the normal operating system on the server.
  • Client NOS performs functions of the data link and network layers only.
  • The trap: a quiz statement claiming the server NOS provides "physical, data link and network" layers is FALSE. Physical is not in the list; application is.
  • A key NOS function is a directory service, e.g. Microsoft's Active Directory Service (ADS), which works much like TCP/IP's DNS.
  • A network profile specifies what resources on each server are available and which devices or people are allowed what access. There must also be a user profile for each person.

Domains and the domain controller named on exam slide

  • A domain is a group of related resources; domains can contain other domains.
  • Linked trees across organisations create a forest of shared network resources.
  • Within each domain there is a server — the domain controller — responsible for resolving address information.

Ethernet is standardised as IEEE 802.3 and is a layer 2 protocol operating at the data link layer. Every Ethernet LAN needs hardware at layer 1.

The switch forwarding table named on exam slide

Process — how a switch learns an address

  1. The switch uses a forwarding table, very similar to a routing table, to know which circuit to use. This makes it a layer 2 switch.
  2. Switches learn addresses to build the forwarding table.
  3. If a switch receives a frame whose destination address is not in the forwarding table, it must send it to all ports.
  4. When the correct computer responds, it is added to the forwarding table.

Definition to hold exactly: a forwarding table tells a switch which port it should send a packet out of to reach the destination computer.

Wireless Ethernet — association and the two coordination functions

Wireless Ethernet is the IEEE 802.11 family, commonly called Wi-Fi. Its logical and physical topologies are the same as hub-based Ethernet: a physical star and a logical bus.

Process — associating with an AP

  1. Before a computer can transmit in a WLAN it must establish an association with a specific AP.
  2. Searching for an available AP is called scanning. A NIC can do this actively or passively.
  3. Active scanning — the NIC transmits a probe frame on all active channels in its frequency range.
  4. Passive scanning — the NIC listens on all channels for a beacon frame sent out by an AP.

Best practice LAN design and performance

  • Wi-Fi is cheaper than wired Ethernet; the largest cost of LANs is paying someone to install the cables. Most organisations install wired Ethernet for desktops and Wi-Fi as overlay networks.
  • Managed APs are wired into a Wi-Fi Controller; they report attached devices and busyness, and the controller can instruct a busy AP to deny access so the laptop connects to the next AP.
  • In the data center, servers sit in server farms or clusters; a load balancer (load balancing switch) acts as a router at the front and stops sending requests to a crashed server.
  • To improve performance, first locate the bottleneck — generally either the network server or a network circuit. Server fixes: faster NOS, second server, upgrade, more memory, more hard drives, RAID.
  • To improve circuit capacity: buy a bigger circuit, or segment the network — in a wired LAN add switches, in a wireless LAN add more APs on different channels.

Good to know

The 50-foot-radius / 50–75-foot square AP design rule and site surveys; guest networks, described as "not secure"; server virtualization; SAN and NAS (a NAS is not a general-purpose computer). Organisations protect internal networks through network segmentation.

Must know

The address space numbers

  • IPv4 uses 32 bits (4 bytes). Number of available addresses = 232 = 4,294,967,296, approximately 4.3 billion.
  • IPv6 uses 128 bits, allowing 3.4 × 1038 addresses. The primary reason for switching was to increase the address size from 32 to 128 bits, because IPv4 addresses were being depleted.
  • IPv4 header = 192-bit (24 bytes), 20 bytes excluding options. IPv6 header = 320-bit (40 bytes).
  • ICANN (Internet Corporation for Assigned Names and Numbers) manages the assignment of network layer and application layer addresses, and sets the rules for new domain names.

Subnetting — the block method, worked

Process — the block method

  1. Find the boundary octet — the octet where the host portion starts.
  2. Count the host bits in that octet. The address block size is 2n.
  3. List the possible starting addresses in that octet: multiples of the block size — 0, k·2n, … while k·2n < 256.
  4. Locate which block the given address falls into. The first address in the block is the network address (host bits all 0s).
  5. The last address in the block is the broadcast address (host bits all 1s).
  6. First host = network address + 1. Last host = broadcast address − 1.

VLSM — variable length subnet masking

  • CIDR (Classless Inter Domain Routing) provides the flexibility of borrowing bits from the host part and using them as network bits — a subnet within a network.
  • Usable hosts per subnet = 2n − 2, where n is the number of host bits. Prefix = 32 − n.
  • The reason VLSM exists: with a uniform mask, point-to-point WAN links needing only two addresses waste the rest. VLSM lets you subnet a subnet.
  • Always allocate largest subnet first, working down to the smallest.

Process — designing a VLSM scheme

  1. Sort the required subnets from most hosts to fewest.
  2. For the largest: find the smallest n where 2n − 2 ≥ hosts needed. Prefix = 32 − n.
  3. Choose the first available starting address on a 2n boundary.
  4. Record network, first host, last host, broadcast. Next network address = broadcast + 1.
  5. Repeat for the next subnet down, starting from where the previous block ended. Blocks must not overlap.
  6. Point-to-point WAN links take /30 — 22 − 2 = 2 usable addresses, exactly what a serial link needs.

Local vs remote — how a host decides

Process — the host's forwarding decision

  1. The source device compares its own IP address and subnet mask against the destination IP address.
  2. Same network portion → destination is local. The data link frame uses the actual MAC address of the destination NIC.
  3. Different network portion → destination is remote. Layer 3 gives Layer 2 the default gateway (DGW) IP address instead.
  4. The frame's destination MAC becomes the router's MAC, not the final destination's. The router then begins the routing process.

A host can send packets to itself (127.0.0.1 in IPv4, ::1 in IPv6), to local hosts, or to remote hosts. A default gateway must have an IP address in the same range as the rest of the LAN, can accept data from the LAN and forward it off the LAN, and can route to other networks. With no default gateway or a bad one, traffic cannot leave the LAN.

Four things a computer needs on a TCP/IP network

  1. Its IP address
  2. A subnet mask
  3. The IP address of a DNS server
  4. The IP address of an IP gateway

A server would also need its application layer address. The most common standard for dynamic addressing is DHCP (Dynamic Host Configuration Protocol).

Address assignment by layer

  • Data link address (MAC) — permanently encoded in each network card; part of the hardware.
  • Network layer address (IP) — assigned by software; managers can assign any they want, but every computer on the same network must be unique.
  • Application layer address — assigned by a software configuration file. Virtually all servers have one; most clients do not.

Four basic operations of the network layer

Addressing end devices · Encapsulation · Routing · De-encapsulation. Two addresses on any subnet cannot be assigned to a computer: the network address (e.g. 128.192.56.0) and the broadcast address (e.g. 128.192.56.255). Routers connect two or more subnets, so they have a separate address on each subnet.

End-to-end walkthrough — known destination address

  1. The application layer passes an HTTP packet to TCP with the destination's Internet address.
  2. TCP ensures the request fits in one segment and hands it to the network layer.
  3. IP checks the subnet mask and recognises the server is outside its subnet.
  4. IP checks its address table and finds the Ethernet address of the router.
  5. The data link layer wraps it in an Ethernet frame and the physical layer transmits it.
  6. The router's data link layer performs error checking, then passes the packet up to its network layer.
  7. The router reads the IP address to determine the final destination and forwards accordingly.
  8. The destination router recognises the address is inside its own subnet, searches its data link layer address table, and passes the packet down with the correct Ethernet address.

Four transport layer functions — and the one that isn't

  1. Taking messages from the application layer
  2. Segmenting — breaking long messages into smaller segments, and reassembling incoming ones
  3. End-to-end delivery of the message
  4. Interfacing with the network layer, and managing the session

Routing is NOT a transport layer function — it belongs to the network layer, and appears as a distractor in the deck's quiz. Equally: the network layer does not provide guaranteed end-to-end delivery (FALSE, and it appears in both Part 1 and Part 2).

Port numbers

TCP and UDP use port numbers to manage multiple, simultaneous conversations. The application tells TCP the source port address and destination port address; these are the first two fields in the TCP segment. The destination port tells the destination which application layer program to send the packet to; the source port tells the receiver which program it came from.

Connection-oriented messaging and the handshakes

  1. The transport layer on both sender and receiver sends a SYN (synchronize) and receives an ACK (acknowledgement) segment — the three-way handshake.
  2. Once established, segments flow between sender and receiver.
  3. On error, the receiver asks the sender to retransmit until received without error. TCP calls this Automatic Repeat reQuest (ARQ).
  4. When transmission is complete, the session is terminated using a four-way handshake.

Connectionless messaging: each packet treated separately, makes its own way, no connection established, packets may arrive out of sequence — so the sender's network layer puts a sequence number on each packet.

  • Continuous ARQ retransmitting only the packets containing an error = Selective-Repeat ARQ, also called LAP-M (Link Access Protocol for Modems).

TCP/IP origin and structure

  • Developed for the U.S. Department of Defense's ARPANET by Vinton Cerf and Bob Kahn in 1974.
  • Two parts: TCP is the transport layer protocol linking the application layer to the network layer; IP routes the message to the final destination.
  • TCP/IP is not a data link protocol — FALSE statement, appears as a quiz item.
  • The network layer does not sit directly between the application and data link layers — the transport layer is in between. Also FALSE, also a quiz item.

Quality of Service

QoS routing is a special type of connection-oriented messaging where different connections get different priorities. RSVP (Resource Reservation Protocol) and RTSP (Real-Time Streaming Protocol) request a minimum guaranteed data rate; once connected they use RTP (Real-Time Transport Protocol) to send packets. RTP does not replace TCP or UDP — each real-time packet is created with RTP then surrounded by a UDP datagram.

Good to know

The security note that the TCP three-way handshake is one of the most exploited security flaws, and that the most basic way to identify someone on the Internet is by their IP address.

Process — how a VLAN moves a frame between switches

VPNs — the three types and the tunnel

A VPN provides the equivalent of a private packet-switched network over the public Internet, by establishing PVCs that run over the Internet. VPN services are very cheap, but only as reliable as the Internet. The PVCs created through the Internet are called tunnels; the VPN is transparent to the users, to the ISP, and to the Internet as a whole.

  • Advantages: low cost and flexibility. Two disadvantages: traffic on the Internet is unpredictable, and security is always a concern — though most VPNs use encryption.

Process — how a VPN carries a packet

  1. The employee starts the VPN software and logs into the VPN gateway at the office.
  2. The VPN software creates a new "interface" on the computer; the gateway assigns an IP address to it.
  3. The computer now thinks it has two connections to the Internet; the VPN software makes the VPN interface the default interface.
  4. The VPN software receives the IP packet, encrypts it, and encapsulates it with an ESP (Encapsulating Security Payload) packet using IPSec encryption.
  5. The ESP packet is passed to the normal Internet interface → IP software → Ethernet software, which adds a frame and transmits it to the employee's router.
  6. The packet travels via the ISP to the office's router, where the process is reversed.
Connects toCh 11 security: IPSec transport mode encrypts just the IP payload, leaving the header unchanged; tunnel mode encrypts the entire IP packet and adds a new one. Tunnel mode is what a VPN uses.

SDWAN — four benefits and three planes

An SDWAN (Software Defined WAN) uses software to control and manage the routers used in the WAN. Four benefits: centralized management; reduces costs by balancing traffic over circuits with different costs and capacities; more visibility so managers see end-to-end traffic flows; good security.

  1. Management Plane — the top level; some vendors call it the Orchestration Plane. The software used to control the network.
  2. Control Plane — the software that controls the network and makes the decisions.
  3. Data Plane — includes the routers that implement the network.

Good to know

Why best-practice WAN design is harder than LAN/BN design: you are buying services from different companies rather than products. A WAN is usually one of the most secure parts of the network unless you're using a VPN over the Internet.

  • ISPs at the same level do not charge one another for transferring messages they exchange — this is peering.
  • Higher-level ISPs charge lower-level ISPs to transmit their data. Each ISP is an autonomous system.
  • A POP (point of presence) is the place at which the ISP provides services to its customers. Messages destined for other customers of the same ISP flow within that ISP's own network.
  • Backbone circuits of major U.S. national ISPs run at SONET OC-192 (10 Gbps); some are experimenting with OC-768 (80 Gbps) and planning OC-3072 (160 Gbps).

Networks must rigidly conform to standards for the transport and network layers, while content and new application protocols develop without restriction.

Building-block design — the three steps

Most organisations now use the building-block process. It starts with a few standard components and uses them over and over, even if they provide more capacity than needed. The goal is simplicity of design; the strategy is sometimes called "narrow and deep".

Process — and it cycles

  1. Needs analysis — understand the fundamental current and future network needs of the various users, departments and applications. Produces a logical network design.
  2. Technology design — examine the available technologies and assess which options will meet users' needs. Produces one or more physical network designs.
  3. Cost assessment — consider the relative costs of the technologies.
  4. Cycle back to needs analysis, refined by the technology and cost information, which triggers further changes. Repeating this loop produces the final design.

Memorise which verb goes with which step — all three appear as separate quiz items keyed on a single word: understand needs → needs analysis; examines available technologies → technology design; considers relative cost → cost assessment.

Why the traditional process is less appropriate now

  • The underlying technology of client and server computers, networking devices, and circuits is changing very rapidly.
  • The growth in network traffic is immense.
  • The balance of costs has changed dramatically.

The distractor to reject: "the most expensive part of any network is the hardware" — that is not one of the reasons. Personnel time is the largest cost, as Ch 12 confirms.

Needs analysis detail

  • Goal: understand why the network is being built and what users and applications it will support.
  • Primary objective of this stage: define the geographic scope of the network and the users and applications that will use it.
  • Reviewing the list of applications and identifying the location of each is called baselining. Understanding current operations provides a baseline against which future design requirements can be gauged.
  • Requirements are organised into mandatory, desirable, and wish-list requirements.
  • Key deliverable: a set of logical network diagrams showing applications, circuits, clients and servers. A logical design does not specify technologies or products.
  • Note the shift: in the past application systems generated most network traffic; now it is Internet use.

Technology design and cost assessment detail

  • Designing circuit capacity = capacity planning. Analysis can focus on average circuit traffic or peak circuit traffic. Circuit loading = the amount of data transmitted on a circuit.
  • The turnpike effect = traffic increases much faster than originally forecast.
  • A bottleneck is a circuit filled almost to capacity, determining whether users get good or bad response times. The bottleneck in most enterprise networks is the WAN and the Internet, not the enterprise campus network.
  • RFP (request for proposal) specifies what equipment, software and services are desired and asks vendors for their best prices.
  • Three deliverables of cost assessment: the RFP, the revised physical network diagram, and the business case expressed in business objectives.
  • To management the network is simply a cost center; the key is speaking management's language.
Connects toThese seven components are the organising frame for the whole second half of the course: Ch 7 = access layer, Ch 8 = distribution and core, Ch 9 = WAN, Ch 10 = Internet access. Ch 6's security note says the components with the tightest security are the core layer and the data center.

Good to know

The four steps of the traditional design process (meet users → estimate data per user → design circuits and get vendor estimates → build), which works well for static or slowly evolving networks; simulation tools that can "discover" the existing network.

Two threat categories, and the four named threat types

  • Ensuring business continuity — primarily availability, with some aspects of data integrity. Three main threats: disruptions, destruction, and disasters.
  • Preventing unauthorized access — primarily confidentiality, but also integrity, since an intruder may change important data.
  • The four valid threat categories are therefore disruption, destruction, disaster, intrusion. "Controlled chaos" is the fake option and appears as a quiz distractor.
  • A hacker gaining access to organisational data files and resources is an intrusion threat.

Three types of control

  1. Preventive — mitigate or stop a person from acting or an event from occurring.
  2. Detective — reveal or discover unwanted events.
  3. Corrective — remedy an unwanted event or an intrusion.

Controls are software, hardware, rules, or procedures that reduce or eliminate threats. They must be reviewed periodically.

Risk assessment — five steps and five impact areas

Process — risk assessment

  1. Develop risk measurement criteria — the measures used to evaluate how a threat could affect the organisation.
  2. Inventory IT assets, then rate them for importance.
  3. Identify threats and create threat scenarios.
  4. Document existing controls.
  5. Identify improvements, focusing first on the highest risks.
  • Five most common business impact areas: financial, productivity, reputation, safety, legal.
  • Three risk assessment frameworks named: OCTAVE, COBIT, NIST guide.
  • An asset is something of value: hardware, software, data or applications. The most important type is the mission-critical application; next is the organisation's data.
  • A threat is any potential occurrence that can do harm, interrupt systems, or cause monetary loss.

Business continuity — the key principle

The key principle in preventing disruption, destruction and disaster is redundancy. A business continuity plan has two parts: controls that prevent these events having a major impact, and a disaster recovery plan. Five major threats to business continuity: viruses, theft, denial of service attacks, device failure, disaster.

  • Macro viruses spread when an infected file is simply opened — contained in documents, emails or spreadsheet files.
  • A worm is a special type of virus that spreads itself without human intervention.
  • UPS — uninterruptible power supply: detects power failures and permits attached devices to continue operating.
  • RAID — redundant array of independent disks. RAID 0 faster than traditional storage; RAID 1 writes duplicate copies on at least two disks; RAID 6 can survive the failure of two drives with no data loss.

  • Readable form = plaintext; encrypted form = ciphertext. Good encryption systems do not depend on keeping the algorithm secret — only the keys.
  • Public key algorithms are invertible: text encrypted with either key can be decrypted by the other. Normally encrypt with public, decrypt with private — doing the reverse creates a digital signature, because only the real user has the private key.
  • PKI begins with a certificate authority (CA), a trusted organisation that vouches for identity. The CA issues a digital certificate — the requestor's public key encrypted using the CA's private key.
  • PGP — freeware public key package by Philip Zimmermann, often used for email.   • IPSec transport mode encrypts just the IP payload, leaving the header unchanged for easy routing. IPSec tunnel mode encrypts the entire IP packet and adds an entirely new IP packet.

User authentication and social engineering

  • Access is based on something you know (usually a password, or a passphrase), something you have, or something you are (biometric systems — fingerprint, retina).
  • Two-factor authentication = a password in conjunction with something you have; commonly the user's mobile phone.
  • Central authentication: the user logs into the authentication server rather than a file or application server; it issues a certificate. The most commonly used authentication protocol is Kerberos.
  • Social engineering = breaking security simply by asking. Phishing is a very common type — a mass email claiming the account was shut down, directing the user to log in at a fake site.
  • A known problem: removal of user accounts when someone leaves — network managers are often not informed of the departure.

IPS and recovery

  • Network-based IPS = a sensor placed on key network circuits. Host-based IPS = a software package installed on a host or server. Many managers install both.
  • Two detection techniques: misuse detection compares monitored activities with signatures of known attacks; anomaly detection compares them with the "normal" set of activities. Most IPSs use both.
  • A security hole is simply a bug that permits unauthorized access. Attacks exploiting a newly discovered hole before a patch is developed are zero-day attacks.
  • Trojan horses are remote access management consoles, sometimes called rootkits. Spyware, adware and DDoS agents are three types of Trojans.
  • Computer forensics = the use of computer analysis techniques to gather evidence for criminal and/or civil trials. A honey pot is an attractive server that contains only fake information.
  • Probably the best security investment is user training. Good security starts with a clear disaster recovery plan and a solid security policy.

Four types of intruder

  1. Casual intruders with only limited knowledge of computer security — script kiddies.
  2. Experts in security motivated by the thrill of the hunt — hackers and crackers.
  3. Professional hackers breaking into corporate or government computers for espionage, fraud, or intentional destruction.
  4. Organisation employees with legitimate access who gain access to information they are not authorized to use.

Three reasons computer security has increased in importance: hacking moved from hobby to profession; hacktivism (hacking to bring attention to a political or social goal) has become more common; mobile devices offer a fertile environment for exploitation.

Good to know

SOX and HIPAA as drivers; an average data breach costing about $3.5 million; the four risk control strategies (accept, mitigate, share — typically insurance — defer); CDP (continuous data protection); the C2 minimum operating system security level.

Definition and the four functional areas

Network management is the process of operating, monitoring, and controlling the network to ensure it works as intended. The four basic functions, each a chapter section:

Managed networks — the single most important performance element

The single most important element contributing to network performance is a managed network that uses managed devices. Managed devices are standard devices such as switches and routers that have small onboard computers to monitor the traffic that flows through the device. Their three additional capabilities:

  1. They record data on the traffic they process.
  2. They monitor the status of other devices around them and can send an alarm message to the network management console on detecting a critical situation.

Quick check

Ten questions across the highest-weighted must-know material. Answer before opening — if you can't answer within about 15 seconds, that's the topic to go back to.

A switch receives a frame whose destination address is not in its forwarding table. What does it do?
It sends the frame out of all ports. When the correct computer responds, that address is added to the forwarding table — this is how switches learn addresses. Note the contrast with the false quiz statement that a switch always broadcasts everything to everyone; it only floods when the address is unknown.
Name the two Wi-Fi coordination functions, their alternative names, and which one solves the hidden node problem.
DCF (Distributed Coordination Function), also called the physical carrier sense method, uses stop-and-wait ARQ. PCF (Point Coordination Function), also called the virtual carrier sense method, uses RTS/CTS through the AP and is the one that solves the hidden node problem. PCF is controlled access, not contention.
For 172.16.117.77/20, give the network address, broadcast address, first host and last host.
Boundary octet is the 3rd; host bits there = 24 − 20 = 4; block size 2⁴ = 16. Blocks run 0, 16, … 112, 128 — so 117 sits in the 112–127 block.
Network 172.16.112.0 · Broadcast 172.16.127.255 · First host 172.16.112.1 · Last host 172.16.127.254. The broadcast takes all twelve remaining host bits as 1s — four in the third octet, eight in the fourth.
In a three-tier architecture, which component handles which logic?
The client handles presentation logic; the application server handles services logic and application logic; a separate database server handles data access logic and data storage. And the follow-on fact from the exam slide: n-tier is generally more scalable than three-tier.
How is a checksum calculated, and how does that differ from CRC?
Checksum: add the decimal value of each character in the message, divide the sum by 255, and use the remainder as the checksum — typically 1 byte, appended to the end. CRC: the message is treated as one long binary number, divided by a preset number, and the remainder is the CRC code (CRC-16, CRC-32). Both use a remainder; the difference is decimal character values vs one long binary number.
Which cable — straight-through or crossover — for router-to-switch, and for router-to-PC?
Router–switch = straight-through (DTE to DCE). Router–PC = crossover. Router-to-PC is the one that breaks the "unlike devices = straight" intuition, so it's the one worth memorising as a bare fact rather than deriving.
A PC sends a packet to a web server three routers away. Which addresses change along the path, and which don't?
The Layer 2 (MAC) addresses are rewritten on every link — source and destination both change at each hop, because data link addressing is purely local. The Layer 3 (IP) addresses never change from original source to final destination. When the destination is remote, the first frame's destination MAC is the default gateway's, not the server's.
What does a NAT firewall actually do, and why does that provide security?
It converts between one set of public IP addresses viewable from the Internet and a second set of private IP addresses hidden from outside the organisation, using an address table to translate private addresses into proxy IP addresses. The security logic stated in the slides: if external intruders cannot see the private IP addresses, they cannot attack those computers. NAT is transparent.
Distinguish DNS from ARP: what does each translate, and how does each find its answer?
DNS translates an application layer address into an IP address, by sending a DNS request packet to its DNS server (the resolving name server), which may escalate to a root server and then the authoritative name server. DNS requests use UDP. ARP translates an IP address into a data link (MAC) address, by sending a broadcast to all computers in its subnet.
Which packet-switched service performs no error control, and what makes MPLS a "layer 2 service"?
Frame relay is an unreliable packet service because it does not perform error control; it uses T carrier and SONET as its circuits. MPLS is called a layer 2 service because it is commonly used with IP for routing at layer 3 — the PAD strips off the Ethernet frame and uses the IP address to route the packet through the carrier's network.
